# Titanic Survival Prediction

## Project Overview

This project explores the Titanic passenger dataset and aims to build a machine learning model that predicts whether a passenger survived.

The project includes exploratory data analysis (EDA), data preprocessing, model training, and evaluation.

## Dataset

The dataset is provided through the [Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic/data).

To obtain the dataset:

1. Visit the Kaggle competition page.
2. Download the Titanic dataset.
3. Extract the downloaded files.
4. Place `train.csv`, `test.csv`, and `gender_submission.csv` inside the `data/raw/` directory.

The dataset files are not included in this repository. Users must download them separately from Kaggle.

## Exploratory Data Analysis

The initial analysis investigates:

- Overall survival distribution.
- Survival rates by sex.
- Survival rates by passenger class.
- Relationships between sex, class, and survival.
- Age distributions and survival patterns.
